- **Capsule shape (optional, feature-flagged)** (, stored `capsule` read as notch, enabled when flag turns on): Appearance -> Shape -> "Island shape" toggle: Notch (default, matching top-attached shape above) / Capsule. Capsule hangs 8px below top of workspace (`CAPSULE_TOP_GAP`, passed to Rust as window top margin); collapsed state is a complete pill: collapsed radius fixed to half of bar height with circular arcs on both ends, unaffected by "Collapsed corner radius" or "Corner shape", hiding both when capsule is chosen; expanded state rounds all four corners to expanded radius, matching detached floating island. Setting key `islandShape` (`notch` / `capsule`), implementation in `features/appearance/islandShape.ts`.
- **Curves: Apple continuous corners** (.3) looked unappealing, switched to Apple continuous corners). Apple corners (60% corner smoothing in Figma) start curving at 1.6R from corner, eliminating seams at straight edges. Drawn in CSS using `corner-shape: superellipse(1.6)` with 1.4R `border-radius`, differing by less than 1% of R from Apple curves (empirically fitted, `features/appearance/cornerShape.ts`). Native hit testing evaluates |x|^n + |y|^n <= r^n (n = 2^1.6) (`island/state.rs`, `passthrough.rs`); when top and bottom radii sum exceeds height, scales down proportionally matching CSS (creating capsule shape when floating collapsed).
- **Radius**: equivalent to 30px Apple corner radius, i.e. expanded `border-radius` 42px; collapsed uses 12 / 30 ratio giving 16.8px (. Radius transitions with width and height between collapsed and expanded states.
- **Expansion and collapse motion** : width, height, and border radius use spring curves (CSS `linear()` damped spring, starting from standstill to prevent first-frame jumps). Expansion takes 560ms with 0.8% overshoot; collapse takes 380ms with critical damping and zero overshoot. Page content fades in 120ms after expansion begins (240ms duration), with 6px downward drift using the same spring. `@supports` detects `linear()`, retaining sampled spring; legacy WebView2 falls back to expansion `cubic-bezier(0.34, 1.3, 0.64, 1)` and collapse `cubic-bezier(0.16, 1, 0.3, 1)`, keeping durations identical. Benchmark script: `node scripts/measure-island-motion.mjs [count] [--scale=1.1] [--trace] [--profile] [--frames]`. Native side enlarges window first, shrinking 600ms after animation ends, issuing one native call at a time.
- **Full motion for all users** (Confirmed 2026-11-13): when system animations are disabled or reduced motion is requested, shape expansion (560ms) / collapse (380ms), collapsed bar and expanded panel transitions, tab fade-in (220ms), and tuck animations still play fully. Many users disable system animations purely for performance rather than motion sensitivity. This exception covers island expansion and collapse motion only; todos, message cards, settings, and dock follow effects still respect reduced motion.
- **Motion animates shape only, without redrawing contents** : each frame updates island shape (`.island`) width, height, and border radius only, calculated in scaled pixels; internal collapsed bar and panels maintain static `scale()`, never animating scale. Panels temporarily acquire dedicated compositor layers during expansion/collapse (approx 640ms, `useMotionLayer.ts`; starting 2026-11-18 tab switching is no longer promoted, preventing subpixel antialiasing blur), undergoing translation, fade, and clipping only without per-frame re-renders; compositor layer revoked once motion finishes. Switching tabs immediately adopts new page height (layout calculated once), allowing shape height transitions to reveal or conceal content. Heavy polling (media status, audio level) skips ticks during transitions (`lib/islandMotion.ts`); audio levels stop polling entirely when expanded.
- **Borders**: expanded state has a 1px subtle white stroke (`.island::after`), defining edges against dark windows; top attached stroke fades within top 30px so the screen edge forms the top boundary. Collapsed state has no stroke and no white lines: tuck hidden draws no indicator bar; clicking collapsed bar buttons leaves no bottom line, illuminating only on keyboard focus. (
- **Concentric inner layers**: page panels maintain 20px margin from island edges, with corner radius equal to "island radius - 20px" using continuous corners; collapsed focus ring insets 3px following island corners. Verified via `tests/regression/island-tour.html?test=1`.
- **Inner boxes use continuous corners** : todo items, inputs, notebook tabs, cards, clipboard rows and thumbnails, translation boxes, messages, album covers, file shelf, and settings cards/controls share the same curve. `tokens.css` defines scale `--corner-xs / sm / md / lg / xl / 2xl` (Apple radii 4 / 6 / 8 / 10 / 12 / 16), paired with `corner-shape: var(--corner-shape)`; draws superellipse(1.6) with 1.4x radius when supported, falling back to standard border-radius otherwise. Capsules (buttons, page dots, toggles) and circles remain true circles to prevent flattening. Nested rule: inner radius = outer radius - padding (CSS radius), not smaller than `--corner-xs`; panels use `--island-panel-radius`, cards flush against 16px padding use `--island-card-radius`.
- Todos: notebook tabs use identical corner radii across four corners; list is no longer 4px narrower than input above (scrollbar space managed with negative margins).
- Legacy settings `islandCornerRadius` and `islandCornerShape` remain unread (defaults used), localStorage keys unchanged.

## Position when Revealing from Tucked State 

- When hover or new messages reveal tucked islands, they return to normal pre-tuck positions. Custom floating positions are preserved; top-attached islands do not shift downward unnecessarily.

## Quick controls (System page)

- A full-width card at the top of the System page with a volume slider and, only on a laptop's built-in screen, a brightness slider. Each row is an icon, the slider and its percentage; the volume icon follows the level (muted, low, high).
- Nothing is drawn until a value has been read, and nothing at all where neither can be read. Brightness never goes below 5%.
- Sliders send their newest value while they move (gathered for 60 ms, without waiting for the slider to rest), never two calls at once, and a change made just before the page closes still goes through. Shown by default; Settings → System → Visible Cards → Volume & Brightness hides the card.


- **Centred clock**: while the collapsed island is quiet (no song playing, and the text shows at most the app name or the todo count), the clock sits in the exact centre, and the island widens if needed so nothing reaches under it.
